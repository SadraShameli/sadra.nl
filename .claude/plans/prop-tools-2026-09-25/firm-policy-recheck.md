# PT-04: Firm policy recheck (fields a to h)

Run date: 2026-09-25. PT-04 deliverable for `.claude/plans/prop-tools-2026-09-25/`.

## Scope and method

| Field | Question |
| --- | --- |
| (a) | Account caps (eval, funded, live) and pooling across plans, sizes and household |
| (b) | Trigger for moving from sim funded to live (payout count, single-day profit, cumulative payouts, discretion) |
| (c) | Effect of going live on other accounts: sim accounts closed or frozen, new eval purchases blocked, cooldown after a live bust |
| (d) | Inactivity rule: day count, day type, minimum qualifying amount |
| (e) | Conduct rules tied to position sizing or rapid re-buys |
| (f) | Copy trading limits |
| (g) | Dashboard balance convention: nominal (starts at account size) or $0-based |
| (h) | Minimum payout request |

Each firm had two agents. A research agent fetched the firm's own pages (help center, product pages, signed terms) and filled in fields (a) to (h) for every plan the engine models. A verifier agent then re-fetched the cited pages on its own and checked each quote.

Allowed sources were the firm's own live pages, plus user pastes of firm pages where a row says so. Agents did not use memory, the prop-firm skill, third-party sites, the Wayback Machine or browser automation. The `.claude/prop-firms` docs served only as a list of URLs to fetch. Neither agent changed any repo file.

Status values:

- **confirmed:** a firm source states it.
- **conflict:** two firm sources disagree.
- **not found:** no page that loaded states it.
- **needs paste:** the source is blocked or not public.

Notation inside quotes:

- `\|` marks a table-cell boundary on the source page.
- `[dash]` replaces an em dash on the source page, so this file contains no em dashes.
- `[then]` marks where the researcher cut a dash that sat between two verbatim fragments.
- `[...]` marks omitted text.
- ` / ` separates separate quoted fragments.
