One row per primary-source document used anywhere in this firm's tree. Update this file every time a source is added, re-fetched, or re-verified.

Take Profit Trader's help center is a standard Zendesk Help Center (`takeprofittraderhelp.zendesk.com`). Its HTML pages (and `robots.txt`/`sitemap.xml`) were Cloudflare-blocked (HTTP 403/404) for direct curl and WebFetch, same as every other firm's help center fetched this session. Unlike those firms, Zendesk exposes a public, unauthenticated Help Center REST API (`/api/v2/help_center/en-us/articles.json`) that was not behind the same block: the full article catalogue (title, section, dates, and full HTML body) was fetched directly through that API in one paginated call (87 articles, one page), with no browser relay needed. Article bodies were converted from HTML to plain text with a small local script (strip script/style tags, convert list items and block-level closes to newlines, decode HTML entities) rather than pasted or hand-copied.
