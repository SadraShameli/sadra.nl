# Lucid Trading: Source Ledger

One row per primary-source document used anywhere in this firm's tree. Update this file every time a source is added, re-fetched, or re-verified.

`lucidtrading.com` (the main marketing site) and `support.lucidtrading.com` (the help center) were both Cloudflare-blocked (`cf-mitigated: challenge`, HTTP 403 "Just a moment...") to raw curl and to WebFetch at the start of this research pass, matching this repo's own engine notes, which describe successful raw-curl access to `lucidtrading.com` as recently as 2026-09-14, four days before this pass began. Partway through this pass, direct raw-curl access to `support.lucidtrading.com`'s individual article pages was retested and found to succeed (HTTP 200, real content, not a challenge page). The block appears to have relaxed for that subdomain's article paths specifically. The main `lucidtrading.com` root domain remained blocked throughout; its homepage content was first taken from a Wayback Machine snapshot, which is not an accepted source and no longer backs any statement in this tree (see the homepage row below). Every `support.lucidtrading.com` article below was fetched directly via raw curl once access succeeded, not through WebFetch's LLM summarization pass. This matters because a WebFetch summarization of one of these same articles (LucidPro Payouts) was cross-checked against the raw version during this pass and found to have blended two separate tables' figures into one incorrect range, confirming the same summarization-corruption risk already documented elsewhere in this doc tree for other firms.
