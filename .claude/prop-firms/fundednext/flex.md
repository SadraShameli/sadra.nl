## Overview

The Flex Challenge is FundedNext Futures' single-fee 1-step model that the firm says "carries the lowest profit targets among all models" (article 17229829; at 100K its $5,000 target equals Rapid Pro's and Rapid Daily's), sold in three sizes ($50K/$100K/$150K). It uses an EOD (End-of-Day) trailing Maximum Loss Limit (MLL) with no Daily Loss Limit at any stage, a 40% consistency rule that applies only during the Challenge Phase, and a 95% funded-stage reward share (this plan's own dedicated articles state 95% outright, including as the Reward Share in the criteria every withdrawal must meet; the firm-wide Reward Share article 17242096, updated 2026-09-30, words Flex both as "traders get a 95% Reward Share" and as "the option to upgrade to a 95% Reward Share", so whether 95% is automatic or an option is not settled by the firm-wide article; see Not Confirmed).

Flex's Challenge Phase and its funded stage ("FundedNext Account") share the same MLL mechanic without a phase split: Flex's own articles state identical contract limits and MLL figures for the Challenge Account and the FundedNext Account ("Flex applies the same limits across the Challenge Account and the FundedNext Account", article 17229829). The FundedNext Account drops the consistency rule entirely and instead gates payouts on a 5-benchmark-day cadence.

## How the Drawdown Works

The Flex Maximum Loss Limit (MLL) follows the firm-wide EOD trailing system: it recalculates once per trading day from the highest EOD balance reached, moves up with profit, never moves down on a loss, and does not react in real time except that an intraday floating loss reaching the MLL causes an instant breach (firm-wide MLL article). For Flex (as for Rapid Pro and Rapid Daily, unlike Legacy's zero-offset lock), article 17230292 states the MLL locks at initial balance + $100 rather than exactly at the initial balance: $50,100 / $100,100 / $150,100 for the three sizes. Articles 17229829 (Challenge) and 17229848 (FundedNext Account) state the same MLL table and the same trailing system for both phases.

Separately, this plan's own FundedNext Account article states the first withdrawal itself resets the MLL to the lock level: "Your first withdrawal resets the MLL to the lock point for your size ($50,100 / $100,100 / $150,100)." and, in its journey list, "Your first withdrawal resets the MLL to your account initial balance + $100." (article 17229848; the older 14878865 wordings "Locks at $50,100 after first payout" and "The first withdrawal resets the maximum loss limit (MLL) back to $50,100, $100,100 & $150,100." survive only at that ID). This is worded as a second, independent trigger path (the payout request itself), reaching the _same_ locked value already described above, not a different figure; how it relates to the profit-based trigger, which this file marks Unconfirmed in dollars, is not stated (see Not Confirmed).

A Hard Breach (the firm-wide articles word it as equity falling below the MLL or a floating loss reaching it) permanently closes the account; a reset is required to trade again. Flex has no Daily Loss Limit, so there is no Soft Breach path for this plan (Soft Breach only applies to plans with a Daily Loss Limit, per the firm-wide soft/hard breach article).

### Worked Example

This example uses the full nominal-balance convention for the $50,000 tier: the account's real balance, starting at a literal $50,000, tracked throughout (matching the account-size label used for Starting Balance in the tables above).

1. The account opens at $50,000 (Starting Balance is Unconfirmed in the tables; $50,000 is taken from the account-size label, see Not Confirmed). The Maximum Loss Limit (MLL) is set at $50,000 − $1,500 = $48,500, the starting threshold the Futures Challenge Terms state for 50K ("50K: $48,500").
2. EOD balance rises to a new high of $51,000 (below the $51,600 trigger, a derived figure, see step 3). The MLL trails up to $51,000 − $1,500 = $49,500.
3. EOD balance reaches a new high of $51,600 exactly. The $51,600 is this file's own derivation ($50,100 locked value + $1,500 drawdown amount), not a source-stated trigger (Unconfirmed in dollars, see Not Confirmed): at that balance the trailing MLL would be $51,600 − $1,500 = $50,100, the source-stated locked value, so the MLL locks at **$50,100** and stops trailing.
4. EOD balance later rises further to $53,000 (a new high). The MLL does not move; it remains fixed at $50,100, since it already locked in step 3.
5. If the account's balance fell below $50,100 (article 17230292: "If the balance ever falls below $100,000, the account is permanently breached" in its Legacy example), or a floating loss reached the MLL during a live trade ("your account is breached instantly"), the account is Hard Breached and permanently closed.

Re-derivation check: starting balance $50,000 + drawdown amount $1,500 + the plan's own $100 lock offset = $51,600, the derived trigger balance used in step 3, and $50,000 + $100 = $50,100, which equals the source-stated locked value. Only the $50,100 is source-stated; the $51,600 is derived.

## Live Transition
